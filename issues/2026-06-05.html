MiniMax M3: First Open-Weight Model to Combine Frontier Coding, 1M Context, and Native Multimodality

High Traction

MiniMax launched M3 on June 1, 2026 — an open-weight model that scores 59% on SWE-Bench Pro (ahead of GPT-5.5, behind Opus 4.7), supports a 1-million-token context window via a new MiniMax Sparse Attention (MSA) mechanism, and handles native multimodal input. Open weights expected on Hugging Face within days.

MiniMax Open Weight Long Context Multimodal Coding AI

Why it matters

M3 is the first open-weight model that doesn't force you to choose between coding quality, context length, and multimodality. The MSA attention mechanism avoids quadratic compute costs by scoring only selected segments, making the 1M context window actually practical to run. For teams self-hosting coding agents on large codebases, this is the model that makes 'feed it the whole repo' viable without frontier API costs.

Use cases

  • Self-host a coding agent that can ingest entire large codebases in a single context window
  • Run multimodal code review — feed screenshots, diagrams, and code together
  • Route high-context coding tasks to M3 while using smaller models for quick completions
  • Evaluate MSA attention for custom long-context applications

It beats Claude Haiku 4.5 across coding benchmarks with a 16-point lead on SWE-Bench Pro, uses adaptive thinking to allocate reasoning budget dynamically, and solves harder problems with up to 60% fewer tokens. Rolling out to all GitHub Copilot tiers now.

Microsoft GitHub Copilot Coding AI Build 2026

For Copilot users, this is the default model getting better without switching providers.

Microsoft Work IQ APIs Go GA June 16: Enterprise Context for Every Agent

High Traction

Microsoft's Work IQ APIs reach general availability on June 16, 2026. They give agents structured access to email, calendar, meetings, chats, files, people, and collaboration patterns across Microsoft 365. Endpoints include A2A (agent-to-agent), a redesigned remote MCP server, and REST API. Pricing is consumption-based via Copilot Credits, independent of M365 Copilot licensing.

Microsoft Work IQ Enterprise MCP Agent Context

Why it matters

This is the missing piece for enterprise agents: structured access to where work actually happens. Before Work IQ, agents could read files or call APIs, but couldn't understand organizational context — who works with whom, what meetings matter, which threads need follow-up. The MCP server endpoint means any MCP-compatible agent (Claude Code, OpenClaw, Cursor) can tap into M365 context without custom integration. The consumption-based pricing decoupled from Copilot licensing means you don't need a Copilot seat to use agents with M365 data.

Use cases

  • Build agents that understand organizational context — who to ask, when to schedule, what files matter
  • Connect Claude Code or OpenClaw to M365 data via the Work IQ MCP server
  • Automate meeting prep, email triage, and follow-up workflows with agent access to M365
  • Decouple agent M365 access from Copilot licensing for cost-effective enterprise deployments

Traction

AI Infrastructure Inference Compute Economics Enterprise
