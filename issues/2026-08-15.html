NVIDIA Releases Nemotron 3.5 Lightning and NeMo Switchyard: Open Models Meet Intelligent Agent Routing

High Traction

NVIDIA ships Nemotron 3.5 Lightning, a 30B-parameter mixture-of-experts model optimized for high-volume agentic tasks within multi-agent systems, alongside NeMo Switchyard, an open-source library that intelligently routes each request to the best model. Thoughtworks validated post-training for legal and healthcare domains in hours.

AI NVIDIA Open Source Agents Infrastructure

Why it matters

Multi-agent systems need a mix of frontier and specialized models, but routing between them is manual and brittle. NeMo Switchyard makes that routing automatic, while Lightning gives you a cheap, capable workhorse for the subtasks that don't need a frontier model. Together, they make the 'system of models' pattern practical.

Use cases

  • Intelligent model routing in multi-agent coding pipelines
  • Cost-efficient specialized agents for code review, testing, docs
  • Domain-specific fine-tuning for enterprise workflows
  • Running capable local agents alongside frontier API calls

Traction

  • Released by NVIDIA as part of Nemotron 3 family expansion
  • NeMo Switchyard is open-source, integrates with popular agent frameworks
  • Thoughtworks published validation: post-trained for legal and healthcare in hours
  • 30B MoE runs on RTX-class hardware

Graphify Hits 106K GitHub Stars: Turn Any Codebase Into a Queryable Knowledge Graph

High Traction

Graphify is a /graphify skill for Claude Code, Cursor, Codex, and Gemini CLI that maps your entire codebase — code, docs, SQL schemas, configs, PDFs — into a real knowledge graph using deterministic tree-sitter AST parsing. No embeddings, no vector store. Every edge is tagged EXTRACTED or INFERRED so you can trace provenance.

DevTools Open Source Code Intelligence Knowledge Graph

Why it matters

Vector search gives you 'similar' results. Graphify gives you 'connected' results — traverse from a function to its callers to the doc that explains the business rule. At 106K stars, it's become the default way developers give their agents structural understanding of codebases instead of just grep-and-hope.

Use cases

  • Giving coding agents structural codebase understanding
  • Tracing dependencies and impact analysis across repos
  • Onboarding to unfamiliar codebases via graph queries
  • Connecting code to docs, schemas, and configs in one graph

Traction

  • 106,466 GitHub stars, 10,362 forks
  • YC-backed (Graphify Labs)
  • Works as a skill across Claude Code, Cursor, Codex, and Gemini CLI
  • Fully local code parsing — no LLM needed for code

OpenAI Ships Symphony: Manage Work, Not Agents — 26.7K Stars on Day One

High Traction

Symphony monitors project boards (starting with Linear), spawns isolated autonomous Codex agents for each task, and provides proof of work — CI status, PR review feedback, complexity analysis, and walkthrough videos. When accepted, agents land the PR safely. Engineers manage the work at a higher level instead of supervising individual agent sessions.

DevTools OpenAI Agents Orchestration Open Source

Why it matters

This is the shift from 'use a coding agent' to 'manage a team of coding agents.' Symphony treats agent runs as isolated implementation units with built-in accountability (proof of work). At 26.7K stars on launch, it's the strongest signal yet that the industry is moving past single-session agent interactions.

Use cases

  • Autonomous task execution from project boards
  • Proof-of-work verification for agent-generated PRs
  • Scaling from one agent to a fleet of parallel agents
  • Integrating coding agents into existing PM workflows

Traction

  • 26,681 GitHub stars on day one
  • 2,718 forks
  • Apache 2.0 license
  • From OpenAI, integrates with Codex
  • Works with Linear for task management

Arcee AI Ships NAC: Open-Source Harness Built for Long-Running Agent Work

Growing

NAC (from Arcee AI) is an Apache-2.0 agent harness that separates temporary execution context from persistent workstream state, specifically addressing context rot in long-horizon tasks. It coordinates parallel agent workers across sessions that can extend hours or days, with each worker getting clean context while the orchestrator maintains the bigger picture.

DevTools Agents Open Source Arcee AI Runtime

Why it matters

Context rot — where agent performance degrades as the context window fills with tool output and false starts — is the biggest unsolved problem in long-running agent work. NAC's architecture treats context as a resource to be managed, not a log to be accumulated, which is a fundamentally different design than most agent harnesses.

Use cases

  • Multi-day agent tasks without context degradation
  • Parallel agent coordination with shared persistent state
  • Long-running refactoring and migration projects
  • Agent sessions that survive context window limits

Traction

  • From Arcee AI, established open-source AI company
  • Apache 2.0 license
  • Addresses context rot (validated by Chroma research)
  • Demonstrated multi-hour and multi-day agent sessions
