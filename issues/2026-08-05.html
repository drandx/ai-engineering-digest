Cursor Open-Sources Mixture-of-Kittens: Production MoE Megakernel for NVL72s

High Traction

Cursor released Mixture-of-Kittens (MoK), their production MoE training megakernel that fuses all MoE communication and computation into a single, fully deterministic kernel for NVL72 racks. MoK eliminates the MoE layer bottleneck that consumed over half of end-to-end training time for their Composer agentic coding model.

AI Infrastructure Open Source Cursor Training

Why it matters

This is rare production ML infrastructure from a company training frontier coding models at scale. MoK addresses the exact GPU utilization problems teams hit when moving to GB300 NVL72s — CPU-GPU synchronization stalls and communication overhead. If you're training MoE models on NVLink-connected GPU clusters, this is the kernel you want.

Use cases

  • Training MoE models on NVL72 racks with fused communication+compute
  • Eliminating CPU-GPU synchronization stalls on GB300 hardware
  • Deterministic MoE training for reproducibility

Traction

  • Open-sourced from Cursor's production training stack for Composer
  • Powers training across tens of thousands of GPUs
  • Built on top of their earlier MXFP8/NVFP4 kernel and warp-decode work
  • Addresses GB300 NVL72-specific bottlenecks that all teams on this hardware face

Microsoft Publishes First Production-Scale Study of Agentic Coding: 13.5M Copilot Sessions Analyzed

High Traction

Microsoft Research published the first production-scale characterization of agentic coding workloads using sampled GitHub Copilot traces from June 2026: 3.2M users, 13.5M sessions, 761M LLM calls, and 95 trillion tokens. Key finding: KV cache hit rates average 90% within a turn but drop to 55% across turn boundaries.

AI Research Microsoft Infrastructure Agents

Why it matters

This is the most comprehensive empirical data on how coding agents actually behave in production. The cache invalidation patterns, long-tailed token distributions, and the gap between quick agent turnarounds and minutes-long user idle periods have direct implications for how you architect inference infrastructure for agentic workloads.

Use cases

  • Optimizing KV cache strategies for agentic inference serving
  • Capacity planning for coding agent infrastructure
  • Understanding real-world agent loop patterns for system design

Traction

  • Published by Microsoft Research with real Copilot production data
  • 3.2M users and 95T tokens analyzed — largest agentic workload study to date
  • Covered by Developers Digest and multiple AI engineering outlets
  • Includes lightweight idle-time predictor for infrastructure optimization

ChainDrop Worm Hits npm: 444 Packages Compromised in Under 4 Hours via Keyv Supply Chain Attack

High Traction

A self-propagating worm called ChainDrop poisoned 444 npm packages and 2,212 versions in under four hours, starting with the popular keyv package. The worm uses Bun for fast execution, harvests CI/CD credentials, and uses an Ethereum smart contract as a dead-drop C2 channel. As of August 4, malicious versions are still reachable on the npm registry.

Security npm Supply Chain Incident

Why it matters

This is the most sophisticated npm supply chain attack to date. ChainDrop doesn't just inject malicious code — it self-propagates by stealing maintainer credentials and publishing poisoned versions of their other packages. If your project depends on keyv (used by got, cacheable-request, and thousands of other packages), you need to audit your lockfile now.

Use cases

  • Auditing your npm lockfile for compromised keyv/cacheable versions
  • Adding supply chain security scanning to CI/CD pipelines
  • Understanding self-propagating supply chain attack patterns

Traction

  • 444 packages and 2,212 versions compromised
  • Covered by CSO Online, The Hacker News, JFrog, Socket.dev, and StepSecurity
  • Live incident as of publication — worm still spreading
  • Uses novel Ethereum dead-drop C2 and Bun-based execution

Sources

  • CSO Online coverage
  • JFrog security research
  • The Hacker News coverage
  • Socket.dev advisory
